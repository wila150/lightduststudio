## 📋 階段 3：添加作品內容

### 3.1 CMS 後台操作

**Step 1：編輯頁面**
1. 登入 CMS：https://lightduststudio-q8qk.onrender.com/cms
2. 點擊「自訂頁面」
3. 找到「攝影服務」頁面
4. 點擊「編輯」

**Step 2：添加項目到各分類**
1. 在頁面中找到「人像與形象攝影」分類
2. 點擊「新增項目」
3. 填寫表單：
   - **標題**：例如「企業領導人形象照」
   - **Slug**：例如「corporate-portrait-001」
   - **描述**：作品的詳細說明
   - **分類**：已自動選中
4. **上傳封面圖片**：拖放或選擇圖片
5. **添加圖庫**：點擊「新增圖片」，上傳相關作品
6. 點擊「保存」

**重複步驟 2-6 為其他分類添加項目**

### 3.2 批量上傳技巧

**提升效率的方法：**

1. **按分類上傳**：
   - 一次專注於一個分類
   - 準備好該分類的所有圖片和文案
   - 連續添加多個項目

2. **使用樣本文案**：
   ```
   [參考 data/sample-photography-items.json]
   ```

3. **圖片預處理**：
   - 如果圖片超過 2048px，系統會自動縮放
   - 無需預先調整大小
   - 系統會自動轉換為 JPG 和 sRGB

## 🆘 常見問題解決

### 問題：初始化腳本失敗

**檢查：**
```bash
# 確認環境變數
echo $GOOGLE_APPLICATION_CREDENTIALS

# 確認 Firebase 認證文件存在
ls -la $GOOGLE_APPLICATION_CREDENTIALS

# 測試 Firebase 連接
node -e "require('firebase-admin'); console.log('Firebase 已連接')"
```

**解決方案：**
- 檢查 `.env` 檔案中的路徑
- 確保 Firebase JSON 文件未損壞
- 重新配置 Firebase 認證

### 問題：圖片上傳失敗

**常見原因和解決：**

| 問題 | 原因 | 解決 |
|------|------|------|
| 檔案過大 | > 2MB | 用更小的圖片或讓系統自動處理 |
| 格式不支援 | 非圖片格式 | 轉換為 JPG 或 PNG |
| 解析度不足 | < 800px | 使用高解析度的原始檔案 |

### 問題：菜單項目未顯示

**檢查：**
1. 導航菜單是否已發佈
2. 頁面本身是否已發佈
3. 菜單項目的排列順序

### 問題：分類篩選不工作

**解決：**
1. 清除瀏覽器快取
2. 確認前端 JavaScript 已加載（public/js/main.js）
3. 確認分類 ID 設置正確
